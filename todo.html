Kế Hoạch Triển Khai Backend

Dự án ThinkBuy (Kiến trúc Modular Monolith / Clean Architecture)

Hiện trạng: Đã dựng khung thư mục (Scaffolding). Các module đang ở dạng trống.

Bước 1

Xây Dựng BuildingBlocks

  • Định nghĩa Exceptions chung & Middleware xử lý lỗi.
  • Thiết lập Behavior cho MediatR (Validation, Logging).
  • Tạo các base class: Entity, AggregateRoot, DomainEvent.
  • Cấu hình shared DTOs (Pagination, Response...).
Bước 2

Thiết Kế Domain & Cơ Sở Dữ Liệu

  • Định nghĩa Entities (Product, Order, User...) trong lớp Domain.
  • Tạo DbContext cho từng Module ở lớp Infrastructure.
  • Cấu hình Entity Framework Core (Fluent API).
  • Tạo Migration và Seed Data ban đầu.
Bước 3

Nghiệp Vụ Application (CQRS)

  • Viết Commands (Create/Update/Delete) & Handlers.
  • Viết Queries (Get) & Handlers (Sử dụng Dapper nếu cần tốc độ).
  • Định nghĩa FluentValidation cho các Requests.
  • Bắn & Lắng nghe Domain Events trong nội bộ Module.
Bước 4

Endpoints & API Gateway

  • Tạo Minimal APIs (Cart, Catalog, Identity...) trong lớp Endpoints.
  • Tích hợp Swagger/OpenAPI (có Bearer Token).
  • Cấu hình Authentication / Authorization (JWT).
  • Đăng ký Dependency Injection tại LaptopCommerce.Api.
Bước 5

Giao Tiếp Inter-Module & Background Worker

  • Cài đặt MassTransit + RabbitMQ để pub/sub Integration Events.
  • Lắng nghe Events cross-module (VD: Đặt hàng -> Trừ kho).
  • Chạy Background Services trong LaptopCommerce.Worker.
  • Tích hợp Redis Caching cho Catalog/Cart.
