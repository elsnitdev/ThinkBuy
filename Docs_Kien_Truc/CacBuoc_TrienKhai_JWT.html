📐 Bản Thiết Kế Chi Tiết: Code JWT

Đi sâu vào từng dòng cấu hình và thư viện cụ thể sẽ sử dụng

1 Cấu hình Thông số JWT (Options Pattern)

Mục tiêu: Đưa cấu hình nhạy cảm ra ngoài file JSON, sau đó map tự động vào một class C# lúc ứng dụng khởi động.

1. appsettings.json (Dự án API)

"Jwt": {
  "Issuer": "LaptopCommerceApi", // Người cấp thẻ
  "Audience": "LaptopCommerceClients", // Đối tượng dùng
  "SecretKey": "ChuoiNayPhaiDaiHon32KyTuDeBaoMat",
  "ExpirationInMinutes": 60
}

2. JwtOptions.cs (Dự án Infrastructure)

public class JwtOptions
{
    public string Issuer { get; set; } = string.Empty;
    public string Audience { get; set; } = string.Empty;
    public string SecretKey { get; set; } = string.Empty;
    public int ExpirationInMinutes { get; set; }
}

👉 Tác động: Nhờ gộp chung thành class JwtOptions, khi code thuật toán sinh Token ta chỉ cần chèn IOptions<JwtOptions> vào là có ngay mọi cấu hình.

2 Thuật toán sinh Token (JwtProvider.cs)

Sử dụng thư viện System.IdentityModel.Tokens.Jwt. Mã nguồn chỗ này sẽ hơi phức tạp do dùng các thuật toán mật mã hóa (Cryptography). Dưới đây là lõi logic chính:

// 1. Đóng gói thông tin người dùng vào Payload (Claims)
var claims = new[] {
    new Claim(JwtRegisteredClaimNames.Sub, user.Id.ToString()),
    new Claim(ClaimTypes.Role, "Admin")
};

// 2. Lấy SecretKey đem đi băm (Hash) để làm Con dấu đỏ (Signature)
var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_options.SecretKey));
var credentials = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

// 3. Ráp 3 phần: Header + Payload + Signature lại thành 1 Token
var token = new JwtSecurityToken(
    _options.Issuer, _options.Audience, claims,
    expires: DateTime.UtcNow.AddMinutes(_options.ExpirationInMinutes),
    signingCredentials: credentials);

// 4. Xuất ra chuỗi chữ (eyJ...) gửi về cho Frontend
return new JwtSecurityTokenHandler().WriteToken(token);

👉 Tác động: Giao diện (Web/App) sau khi gọi API Đăng nhập thành công sẽ nhận được chuỗi chữ từ hàm này và tự lưu vào trình duyệt (LocalStorage).

3 Đăng ký lính gác chặn API (Program.cs)

Vào dự án LaptopCommerce.Api, cài thư viện Microsoft.AspNetCore.Authentication.JwtBearer. Cấu hình Middleware để mọi Request đi vào đều bị chặn lại xét giấy tờ.

builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true, // Token hết hạn chưa?
            ValidateIssuerSigningKey = true, // Chữ ký có bị làm giả không?
            
            ValidIssuer = configuration["Jwt:Issuer"],
            ValidAudience = configuration["Jwt:Audience"],
            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes(configuration["Jwt:SecretKey"]))
        };
    });

// Chèn chốt gác vào Pipeline của Web Server
app.UseAuthentication();
app.UseAuthorization();

👉 Tác động: Kể từ bây giờ, bất kỳ Controller nào có chữ [Authorize] trên đầu sẽ tự động chặn các người dùng gửi Token sai hoặc gửi Token hết hạn.
