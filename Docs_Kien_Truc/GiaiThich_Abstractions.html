🔌 1. ICacheService (Mô hình Ổ cắm điện)

ICacheService đóng vai trò như một chiếc ổ cắm điện trên tường. Tầng nghiệp vụ (Ví dụ: Tính năng lấy danh sách sản phẩm) chỉ cần biết cách "cắm phích" vào ổ để lấy dữ liệu (Gọi hàm GetAsync).

Nó hoàn toàn không cần quan tâm đằng sau bức tường đó là nguồn điện từ đâu (Redis hay Memory Cache). Nhờ vậy, ta có thể dễ dàng thay đổi công nghệ Caching trong tương lai mà không làm hỏng tính năng hiện tại.

ProductService.cs (Cách ứng dụng thực tế) 
public async Task<List<Laptop>> GetDanhSachLaptopAsync()
{
    string cacheKey = "laptop_trang_chu";

    // 1. "Cắm phích": Thử lấy dữ liệu trực tiếp từ Cache (Rất nhanh, 1-2ms)
    var laptops = await _cacheService.GetAsync<List<Laptop>>(cacheKey);

    if (laptops == null)
    {
        // 2. Nếu Cache trống (Ví dụ: Server vừa restart), lúc này mới phải lội xuống Database
        laptops = await _dbContext.Laptops.ToListAsync();

        // 3. Cất ngay dữ liệu vào Cache để lần sau lấy cho lẹ (Hẹn giờ 30 phút sau tự hủy)
        await _cacheService.SetAsync(cacheKey, laptops, TimeSpan.FromMinutes(30));
    }

    return laptops;
}

🛒 2. IUnitOfWork (Mô hình Nút Thanh Toán)

sequenceDiagram autonumber participant App as Tầng Nghiệp Vụ participant UoW as IUnitOfWork participant DB as Database App->>DB: Trừ số lượng kho (Lưu Nháp) App->>DB: Tạo Đơn hàng (Lưu Nháp) alt Thành công toàn bộ App->>UoW: Gọi SaveChangesAsync() UoW->>DB: 🟢 Ghi nhận chính thức (COMMIT) else Lỗi ở giữa chừng (Mất điện) App--xUoW: Phát hiện Lỗi UoW->>DB: 🔴 Hủy toàn bộ (ROLLBACK) DB-->>App: Trả lại số lượng kho như cũ end

IUnitOfWork đại diện cho một Giao dịch (Transaction) trọn vẹn. Nó giống như việc bạn đi siêu thị bỏ đồ vào giỏ. Mọi thay đổi trong cơ sở dữ liệu (Database) lúc này chỉ là lưu nháp.

Chỉ khi toàn bộ các bước logic (Trừ tồn kho, Tạo hóa đơn, Tính tiền) chạy trơn tru, ta mới gọi hàm SaveChangesAsync() để Ghi nhận chính thức (Commit).

Nếu có bất kỳ lỗi nào xảy ra giữa chừng, hệ thống tự động Hủy bỏ (Rollback), đảm bảo dữ liệu không bị sai lệch (ví dụ: mất hàng trong kho nhưng khách chưa lên đơn).
