🏆 Tổng Kết Giai Đoạn 0: Hạ Tầng Cốt Lõi

Tài liệu này lưu trữ toàn bộ cấu trúc thư mục, chức năng của từng file và luồng hoạt động của bộ khung Architecture mà chúng ta đã xây dựng cho dự án LaptopCommerce (Modular Monolith).

📂 Cấu trúc File & Chức năng chi tiết

1. LaptopCommerce.SharedKernel

Mục đích: Trái tim của hệ thống. Chứa các khái niệm cốt lõi nhất (DDD Base) và mẫu thiết kế xử lý lỗi (Result Pattern) dùng chung cho TOÀN BỘ dự án.

📁 Domain/
📄 Entity.cs: Lớp cha của mọi thực thể. Cung cấp cơ chế so sánh 2 thực thể dựa vào ID.
📄 AggregateRoot.cs: Thực thể Gốc. Chứa danh sách các Domain Events (Sự kiện nội bộ).
📄 IDomainEvent.cs: Đánh dấu một sự kiện xảy ra bên trong 1 Module.
📁 Results/
📄 Error.cs: Định nghĩa chuẩn Lỗi (Mã lỗi, Lời nhắn).
📄 Result.cs / ResultT.cs: Thay thế hoàn toàn cho Exception (Try/Catch). Ép mọi hàm phải trả về trạng thái Thành Công/Thất Bại rõ ràng.

2. LaptopCommerce.Application.Abstractions

Mục đích: Định nghĩa các "Ổ cắm" (Interfaces). Ép kiến trúc tuân thủ CQRS. Không chứa code thực thi (chỉ khai báo luật lệ).

📁 Messaging/ (Kiến trúc CQRS)
📄 ICommand.cs: Lệnh GHI dữ liệu (Bắt buộc trả về Result).
📄 IQuery.cs: Lệnh ĐỌC dữ liệu (Bắt buộc trả về Result<T>).
📄 ICommandHandler/IQueryHandler: Người xử lý lệnh.
📁 Caching/ & 📁 Data/ & 📁 Authentication/
📄 ICacheService.cs: Hợp đồng cho dịch vụ Cache (Redis).
📄 IUnitOfWork.cs: Hợp đồng lưu DB (Tránh lưu lắt nhắt).
📄 IJwtProvider.cs: Hợp đồng sinh Token JWT.

3. LaptopCommerce.Contracts

Mục đích: Đại sứ quán. Nơi chứa các "Sự kiện Tích hợp" (Integration Events) để các Module khác nhau nói chuyện mà không bị phụ thuộc code vào nhau.

📁 Events/
📄 IIntegrationEvent.cs: Chuẩn chung cho mọi tin nhắn liên module.
📄 IntegrationEvent.cs: Dùng từ khóa record để đảm bảo tính Bất Biến (Immutability). Tự động sinh ID và Timestamp (lịch sử không thể thay đổi).
📄 IEventBus.cs: Giao diện trạm bưu điện (để quăng sự kiện lên RabbitMQ/Kafka).

4. LaptopCommerce.Infrastructure.Shared

Mục đích: Các "Phích cắm" thực tế. Triển khai code tương tác trực tiếp với công nghệ bên ngoài (Redis, JWT, MySQL).

📁 Caching/
📄 RedisCacheService.cs: Kết nối Redis. Chứa logic Deserialize JSON và cài đặt Bom hẹn giờ (TTL) chống đầy RAM.
📁 Data/
📄 DbConnectionFactory.cs: Mở đường ống kết nối thô (Raw Connection) tới MySQL dành riêng cho các truy vấn siêu tốc (Dapper).
📁 Authentication/
📄 JwtOptions.cs: Bản thiết kế hứng dữ liệu từ appsettings.
📄 JwtProvider.cs: Máy in thẻ JWT (Băm chữ ký bằng HMAC SHA256).

⚙️ Entry Point & Luồng chạy Hệ thống

LaptopCommerce.Api (Cổng chính)

Đây là dự án Web API, đóng vai trò Cửa ngõ. Các file quan trọng nhất tại đây:

  • appsettings.json: Lưu các biến môi trường nhạy cảm (JWT Secret, Database Connection String). Giúp linh hoạt thay đổi trên Production mà không cần build lại code.
  • Program.cs: Nơi cài đặt Middleware. Nổi bật nhất là việc thiết lập Bảo vệ cổng AddJwtBearer, kiểm tra dấu mộc đỏ trước khi cho request đi vào các Module.
